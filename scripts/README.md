# Системные скрипты и автоматизация

Каталог предназначен для размещения скриптов автоматизации, вспомогательных сценариев системного мониторинга и конфигурационных файлов, разрабатываемых в ходе выполнения курса «Операционные системы».

В последующих лабораторных работах здесь будут размещаться:
- Скрипты автоматического сбора телеметрии и мониторинга загрузки оборудования.
- Сценарии профилирования процессов и анализа системных вызовов ядра.
- Скрипты для сборки и тестирования модулей ядра и системных утилит.
