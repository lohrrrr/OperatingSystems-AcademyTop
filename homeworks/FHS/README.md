# Самостоятельная работа: иерархия файлов Linux

Исследуйте дерево каталогов своей Ubuntu и объясните назначение выбранных
путей по FHS. Укажите наблюдения, подтверждённые командами и выводом из
собственной системы.

Рекомендуемый набор для осмотра: `/`, домашний каталог, `/etc`, `/usr`,
`/var`, `/tmp`, `/run`, `/dev`, `/proc`, `/sys`. Для каждого пути выберите
безопасную команду просмотра и запишите, относится ли содержимое к
настройкам, программам, изменяемым данным, устройствам или сведениям ядра.

## Что сдать

- таблицу «путь — назначение — пример — команда проверки»;
- пояснение абсолютного и относительного пути;
- сравнение inode файла и жёсткой ссылки в своей рабочей папке;
- короткий вывод о различиях между FHS и конкретной системой Ubuntu.

Не редактируйте системные файлы и не прикладывайте к отчёту закрытые данные.
