# Курс: Операционные системы (os-linux-course)

Репозиторий предназначен для выполнения и фиксации практических и лабораторных работ по курсу «Операционные системы», ведения инженерных отчётов по исследованию системных сред и документирования результатов.

## Цели на курс
- [ ] Научиться не убивать систему в первые 10 секунд "а что если поставить openrc вместо systemd"
- [x] Портировать линукс на NTFS: [Alpine-NTFS, дистрибутив на базе Alpine что патчит initramfs позволяя ядру грузиться с NTFS раздела](https://github.com/lohrrrr/Alpine-NTFS)
- [ ] Портировать линукс на APFS
- [ ] Выработать привычку делать нормальные коммиты
- [ ] Доделать свою Linux-совместимую ОС

## Структура репозитория
- `assets/screenshots/` — графические подтверждения, снимки экрана с результатами диагностики.
- `labs/` — материалы лабораторных исследований и воспроизводимые инструкции по работам.
- `reports/` — системные паспорта, классификация архитектур ОС и журналы работы с инструментами.
- `scripts/` — автоматизационные скрипты мониторинга, сбора метрик и конфигурации среды.

## Правила ведения репозитория
- **Модульность**: каждая работа оформляется в отдельном каталоге внутри `labs/`.
- **Чистота истории**: последовательные, осмысленные коммиты, отражающие конкретные этапы работы.
- **Информационная безопасность**: строгое отсутствие персональных данных, серийных номеров, сетевых адресов и секретов.
- **Интеграция материалов**: все скриншоты встроены в отчёты через относительные пути и снабжены текстовыми пояснениями.
