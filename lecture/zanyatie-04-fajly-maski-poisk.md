# Занятие 4. Файлы, шаблоны имён, поиск и справка

## Повседневные операции

`mkdir -p` создаёт недостающие каталоги в пути. `touch` создаёт пустой файл,
если его нет, либо обновляет время изменения существующего. `cp` копирует,
`mv` перемещает или переименовывает, `rm` удаляет файл, а `rmdir` подходит
только для пустого каталога. Для копирования дерева используют `cp -r`.

Перед перезаписью или удалением проверяйте целевой путь. Интерактивные
ключи `-i` помогают избежать случайной замены или удаления; `rm` не
предоставляет обычную корзину. Имена с пробелами заключают в кавычки или
экранируют пробел.

## Шаблоны оболочки

Оболочка может раскрыть шаблон до запуска программы:

| Обозначение | Значение |
|---|---|
| `*` | последовательность символов любой длины |
| `?` | один произвольный символ |
| `[abc]` | один символ из указанного набора |
| `[!abc]` | один символ вне набора |
| `{a,b}` | один из заданных вариантов |

Шаблоны в кавычках не раскрываются оболочкой. Обычная `*` не включает
скрытые имена. Сначала проверьте результат, например через `printf` или `ls`,
и только затем применяйте опасную команду.

## Поиск объектов и программ

`find` обходит каталоги и отбирает объекты по условиям: `-name`, `-type`,
`-size` и `-mtime`. Шаблон для `-name` обычно передают в кавычках, чтобы
его обрабатывал именно `find`. Прежде чем использовать действия `-exec` или
`-delete`, изучите список найденных путей.

`locate` ищет по индексной базе, поэтому результат может отставать от
реального состояния диска до обновления базы. `which` проверяет исполняемые
файлы в `PATH`, тогда как `type` также распознаёт встроенные команды.

## Справочная система

`man имя` открывает подробную страницу. `man 5 passwd` выбирает раздел
о форматах файлов, а не страницу одноимённой команды. В просмотрщике `/`
ищет текст, `n` переходит к следующему совпадению, `q` закрывает страницу.
`man -k` ищет по кратким описаниям, `--help` показывает краткие параметры
программы, а `help` предназначен для встроенных команд оболочки.

## Практика

Создайте отдельную учебную папку, потренируйтесь копировать и переименовывать
файлы, проверьте несколько шаблонов и найдите файлы по размеру и имени.
В журнале фиксируйте команду, наблюдаемый результат и более безопасный
вариант выполнения. Не запускайте массовое удаление на системных путях.
