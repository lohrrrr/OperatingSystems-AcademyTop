# Занятие 2. Назначение, развитие и разновидности ОС

## Роль операционной системы

Операционная система управляет аппаратными ресурсами и предоставляет
программам единый способ ими пользоваться. Упрощённо путь запроса выглядит
так: приложение обращается к библиотеке, та при необходимости вызывает
службу ядра, а ядро взаимодействует с устройством.

Обычная программа не должна произвольно управлять всем оборудованием.
Процессор разделяет выполнение на пользовательский и привилегированный
режимы. Программа запрашивает операцию у ядра посредством **системного
вызова**; ядро проверяет запрос, выполняет разрешённую работу и возвращает
результат.

## Как возникали функции ОС

Историю удобно рассматривать как последовательность задач и решений.
Когда компьютер выполнял одну программу целиком, оператор вручную запускал
следующую. Пакетная обработка автоматизировала очереди заданий. Позднее
мультипрограммирование позволило держать несколько работ в памяти, а
разделение времени — интерактивно обслуживать пользователей.

Персональные компьютеры сделали систему доступной одному владельцу,
графические интерфейсы упростили повседневное управление, а Linux развивался
как открытое ядро. Современные мобильные платформы добавили особые требования
к энергии, сенсорам и изоляции приложений. Новые подходы не отменяли прежние:
планировщик и сейчас распределяет процессор между конкурирующими задачами.

## Основные функции

| Область | Примеры работы ОС |
|---|---|
| Процессы | запуск программ, распределение процессорного времени |
| Память | выделение адресного пространства и изоляция процессов |
| Файлы | хранение данных в файлах и каталогах |
| Устройства | взаимодействие через драйверы |
| Защита | проверка учётных данных и разрешений |
| Интерфейс | графическая среда и командная оболочка |

При переключении процессора между задачами система сохраняет состояние
одной задачи и восстанавливает состояние другой. Это называется **сменой
контекста**.

## Как классифицируют системы

Классификации независимы друг от друга: систему можно одновременно описать
по числу задач, назначению и типу интерфейса.

- По многозадачности различают системы с одной задачей и с несколькими;
  переключение может быть кооперативным или вытесняющим.
- По числу пользователей — однопользовательские и многопользовательские.
- По назначению — настольные, серверные, мобильные, встроенные и
  предназначенные для систем реального времени.
- По интерфейсу — командные, графические либо совмещающие оба варианта.
- По архитектуре процессора — например, 32- и 64-разрядные.
- По модели распространения — проприетарные и свободные.

Система реального времени ценна предсказуемым соблюдением срока реакции,
а не просто высокой средней скоростью. По устройству ядра выделяют
монолитные, микроядерные и гибридные решения. **Linux** — ядро; **Ubuntu** —
дистрибутив, в который входят ядро, системные программы и пакеты.

## Практика

Сравните основную ОС компьютера и Ubuntu в виртуальной машине. Запишите
назначение каждой, тип интерфейса, архитектуру и модель лицензирования.
В Ubuntu можно посмотреть версию ядра командой `uname -r`, а сведения
о выпуске — через `lsb_release -a`.
