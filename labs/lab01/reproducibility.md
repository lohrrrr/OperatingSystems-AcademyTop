# Инструкция по воспроизведению исследования (Reproducibility Guide)

Данное руководство позволяет независимому исследователю пошагово повторить процедуру сбора диагностических данных на компьютере под управлением Alpine Linux (RISC-V 64-bit).

## Шаг 1. Вход в систему и запуск графической среды
1. Выполните вход в учетную запись пользователя.
2. Для запуска оконного менеджера выполните команду:
```bash
LIBGL_ALWAYS_SOFTWARE=1 xinit /usr/bin/openbox-session -- :0 vt1
```
3. В появившемся графическом окружении откройте терминал `xterm` либо `xfce4-terminal` либо `kitty` либо `konsole` либо `console` либо `gnome-terminal`.

## Шаг 2. Сбор сведений об ОС (Аналог winver)
1. В окне терминала выполните:
```bash
fastfetch
```
2. Убедитесь в корректности вывода версии дистрибутива, релиза ядра и архитектуры.
3. Сохраните снимок окна в `assets/screenshots/01_winver.png`.

## Шаг 3. Сбор общих сведений о системе (About)
1. Запустите окно настроек системы:
```bash
xfce4-settings-manager &
```
2. Откройте раздел «О системе».
3. Сохраните снимок окна в `assets/screenshots/02_about.png`.

## Шаг 4. Мониторинг процессора и оперативной памяти
1. Запустите диспетчер задач:
```bash
xfce4-taskmanager &
```
2. Разверните окно для отображения графиков нагрузки процессора и шкал оперативной памяти.
3. Сохраните снимки:
   - График ЦП — `assets/screenshots/03_cpu.png`.
   - График памяти — `assets/screenshots/04_memory.png`.
   - Список процессов — `assets/screenshots/07_processes.png`.

## Шаг 5. Диагностика накопителя и файловой системы
1. Запустите графический анализатор:
```bash
baobab &
```
2. Выберите корневой раздел `/` и дождитесь завершения сканирования.
3. Сохраните снимок окна в `assets/screenshots/05_disk.png`.

## Шаг 6. Диагностика видеоадаптера
1. В окне терминала выполните:
```bash
glxinfo -B
lspci | grep -i "vga\|virtio"
```
2. Сохраните снимок экрана с выводом параметров видеоадаптера и рендерера в `assets/screenshots/06_gpu.png`.

## Шаг 7. Сводная системная диагностика (Аналог msinfo32)
1. Выполните опрос ключевых подсистем в терминале:
```bash
inxi -Fz
```
2. Сохраните снимок окна в `assets/screenshots/08_msinfo32.png`.
