# Практические материалы

Материалы собраны по темам занятий. Перед командами, изменяющими файлы,
пользователей, права или процессы, проверьте текущий каталог и работайте
в виртуальной машине с тестовыми данными. Результаты вашей первой лабораторной
и отчёты в `labs/` и `reports/` остаются отдельными и не заменяются этими
заданиями.

| № | Тема | Материалы |
|---:|---|---|
| 1 | Установка Ubuntu | [Подготовка VM](zanyatie-01-ubuntu-virtualbox/README.md) |
| 2 | Назначение ОС | [Сравнение систем](zanyatie-02-istoriya-i-vidy-os/README.md) |
| 3 | FHS | [Практика по дереву файлов](zanyatie-03-fajlovaya-sistema/README.md) |
| 4 | Файлы и поиск | [Практика по файлам и справке](zanyatie-04-fajly-maski-poisk/README.md) |
| 5 | Пользователи и группы | [Матрица доступа](zanyatie-05-polzovateli-gruppy-sudo/README.md) |
| 6 | Права и umask | [Проверка разрешений](zanyatie-06-prava-umask/README.md) |
| 7 | Процессы | [Управление тестовыми процессами](zanyatie-07-processy-signaly/README.md) |
| 8 | Диагностика | [Анализ нагрузки](zanyatie-08-diagnostika/README.md) |

Исходные DOCX-задания не включены. Подробные памятки и шаблоны находятся
рядом с практикой соответствующего занятия.

Исполняемые скрипты из исходного набора сюда не перенесены: часть из них
удаляет фиксированные каталоги, меняет системные учётные записи и права,
завершает процессы по шаблону или создаёт интенсивную нагрузку. Вместо
автоматического запуска задания описаны как ручные упражнения в изолированной
виртуальной машине.
