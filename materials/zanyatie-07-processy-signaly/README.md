# Практика: процессы и сигналы

Все эксперименты выполняйте со своими короткоживущими тестовыми процессами.
Памятка по основным понятиям находится в [`CHEATSHEET.md`](CHEATSHEET.md).

Соберите таблицу с PID, PPID, состоянием, командой запуска и сигналом,
которым был завершён процесс. Для остановленного задания укажите, каким
способом его возобновили.
