# Памятка: файлы и поиск

- `mkdir -p` создаёт недостающие уровни каталогов.
- `cp -i` запрашивает подтверждение перед заменой; `cp -r` копирует каталог.
- `mv` используется и для перемещения, и для переименования.
- `rm` удаляет без корзины; `rmdir` срабатывает только для пустого каталога.
- `*` соответствует любому количеству символов, `?` — одному символу.
- Для `find -name` шаблон передавайте в кавычках, чтобы раскрытие выполнил find.
- Сначала просмотрите результаты `find`, потом выбирайте действие над ними.
- `locate` использует базу индекса и может показывать устаревшие сведения.
- `man`, `--help` и `help` дают разные формы документации.
- В просмотрщике man `/` начинает поиск, `n` переходит дальше, `q` закрывает.
