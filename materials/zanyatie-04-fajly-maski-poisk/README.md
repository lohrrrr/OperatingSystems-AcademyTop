# Практика: файлы, маски и справка

Работайте только в отдельной учебной папке. Создайте несколько текстовых
файлов и один вложенный каталог, затем выполните упражнения из
[`PRACTICE.md`](PRACTICE.md). Краткие пояснения команд находятся в
[`CHEATSHEET.md`](CHEATSHEET.md).

Перед перезаписью используйте интерактивный режим. Перед удалением по маске
покажите список совпадений и убедитесь, что он не пустой и содержит только
ожидаемые пути. Не применяйте `rm` к каталогам с системными данными.
