# Практическая работа: файлы и поиск

## Подготовка

Создайте рабочий каталог, несколько файлов с разными расширениями и один
файл с именем, начинающимся с точки. Проверьте содержимое через `ls` и `ls -A`.

## Задания

1. Создайте вложенные каталоги с `mkdir -p`.
2. Скопируйте один файл в резервную папку, переименуйте копию через `mv`.
3. Проверьте совпадения для `*.txt`, `?` и набора символов.
4. Сравните вывод команды с шаблоном в кавычках и без кавычек.
5. Найдите файл по имени и типу посредством `find`.
6. Откройте справку для `find`, а затем найдите описание ключа поиска.
7. Запишите команды, результат и одно замечание о безопасном выполнении.

Перед любым удалением выполните команду просмотра с тем же шаблоном. Не
используйте ключ `-f` и не запускайте `-delete`, пока не проверили выборку.
