# Практика: сравнение операционных систем

Составьте краткую таблицу для хостовой системы и Ubuntu VM. Для каждой
запишите назначение, архитектуру, интерфейс, модель лицензирования и пример
управляемого ресурса. В отдельном абзаце проследите путь одного запроса
приложения к файлу: приложение, библиотека, системный вызов, ядро, устройство.

## Вывод

Опишите одну функцию современной ОС, которая появилась как ответ на
историческую проблему. Различайте понятия «ядро», «дистрибутив» и «оболочка».
