# Памятка: права доступа

- Порядок категорий в режиме: владелец, группа, остальные.
- Для файла `r` читает, `w` изменяет, `x` запускает; для каталога эти биты
  разрешают просмотр имён, изменение содержимого и проход по пути.
- Числовые значения: `r=4`, `w=2`, `x=1`; `640` означает `rw-r-----`.
- `chmod` меняет режим; `chown` — владельца; `chgrp` — группу.
- `umask` снимает биты с базового режима при создании файлов и каталогов.
- Sticky bit ограничивает удаление в общем каталоге; setgid может закрепить
  наследование группы каталогом.
- ACL расширяют стандартную модель доступа; используйте `getfacl` для проверки.
- Рекурсивный `-R` может затронуть огромное дерево: перед запуском сверьте путь.
