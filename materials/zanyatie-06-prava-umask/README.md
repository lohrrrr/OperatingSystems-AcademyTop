# Практика: права и umask

Используйте тестовые файлы, не системные каталоги. Задание предлагает
наблюдать, как владелец, группа и остальные получают разные разрешения.
Сначала изучите [`PRACTICE.md`](PRACTICE.md), краткие определения —
в [`CHEATSHEET.md`](CHEATSHEET.md).

Завершите работу таблицей «объект — владелец — группа — режим — ожидаемый
доступ». Для каждого вывода объясните, какое правило определило результат.
