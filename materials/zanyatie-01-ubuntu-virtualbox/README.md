# Практика: подготовка Ubuntu VM

1. Запишите архитектуру хоста и подходящую архитектуру ISO-образа.
2. Создайте виртуальную машину, отметив выделенные память, число процессоров
   и размер виртуального диска.
3. Пройдите установку, проверяя, что выбран виртуальный диск.
4. После первого запуска обновите систему и сохраните snapshot.
5. Проверьте, что VM можно корректно выключить и снова запустить.

## Отчёт

Зафиксируйте версию Ubuntu, параметры VM, выбранную архитектуру и имя снимка.
Не публикуйте имя пользователя, серийные номера, ключи активации или другие
персональные сведения.
