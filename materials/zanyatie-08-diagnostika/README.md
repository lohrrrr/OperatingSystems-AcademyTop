# Практика: разбор нагрузки

Учебная диагностика выполняется по схеме «система → процесс → причина».
Используйте [`PRACTICE.md`](PRACTICE.md) и памятку
[`CHEATSHEET.md`](CHEATSHEET.md). Не создавайте искусственную нагрузку,
способную повесить компьютер, и не завершайте системные процессы.

В конце подготовьте небольшой разбор: симптом, собранные показатели,
подтверждённая причина, безопасные действия и идея профилактики.
