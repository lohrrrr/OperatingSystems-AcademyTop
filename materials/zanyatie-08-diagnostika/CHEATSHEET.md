# Памятка: диагностика ресурсов

- Сравнивайте load average с числом CPU и дополняйте оценку данными о процессах.
- В `free -h` для общей оценки доступной памяти смотрите `available`.
- `top` и `htop` дают динамический обзор; `ps` удобен для разового снимка.
- `ps --sort=-%cpu` и сортировка по RSS помогают найти кандидатов для анализа.
- `pstree -s -p PID` показывает цепочку родителей; `/proc/PID/cwd` — рабочий каталог.
- `nice` и `renice` влияют на приоритет, а не на вычислительную скорость сами по себе.
- `time` разделяет прошедшее время и время CPU в пользовательском коде и ядре.
- Диагностика должна предшествовать завершению процесса; начинайте с TERM.
- Postmortem фиксирует симптом, причину, действия и предотвращение повторения.
