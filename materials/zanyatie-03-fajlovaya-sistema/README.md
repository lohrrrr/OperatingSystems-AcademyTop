# Практика: обзор дерева файлов

Исследуйте корень системы и домашний каталог, затем выберите по одному
примеру конфигурации, программы, журнала, устройства и псевдофайла ядра.
Запишите путь, команду наблюдения и назначение объекта.

```bash
pwd
ls -lah /
ls -la ~
findmnt -T /
df -h .
```

## Ссылки и итог

В отдельной учебной папке создайте файл и жёсткую ссылку на него. Сравните
их inode через `ls -li`, затем создайте символическую ссылку и изучите её
через `readlink`. Не экспериментируйте с системными каталогами.

В отчёте ответьте, чем абсолютный путь отличается от относительного и
какие сведения в вашей системе находятся в `/etc`, `/var`, `/dev` и `/proc`.
Для каждого снимка укажите, какую команду выполняли и что из вывода следует.
