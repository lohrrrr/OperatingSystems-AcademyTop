# Памятка: файловая система

- `/` — вершина дерева; абсолютные пути начинаются с неё.
- `~` обычно указывает на домашний каталог текущего пользователя.
- `/etc` хранит настройки; `/var/log` — журналы; `/var/lib` — состояние программ.
- `/dev` содержит специальные устройства; `/proc` и `/sys` отражают сведения ядра.
- `PATH` задаёт каталоги поиска исполняемых файлов.
- `stat` показывает метаданные, `ls -li` — inode объектов.
- Жёсткие ссылки указывают на тот же inode; символические содержат путь к цели.
- `findmnt` показывает подключение файловых систем, `df` — свободное место,
  `du` — размер выбранного дерева.
- Не изменяйте системные файлы ради практики; используйте собственную папку.
