# Памятка: пользователи, группы и sudo

- `id` показывает UID, GID и дополнительные группы текущего процесса.
- `getent passwd имя` и `getent group имя` читают учётные записи через системную
  базу, не полагаясь на прямой разбор файла.
- `/etc/passwd` содержит поля учётной записи; секретные данные паролей
  находятся отдельно и закрыты от обычного чтения.
- `sudo -l` показывает команды, разрешённые текущему пользователю.
- `sudo -u имя команда` позволяет проверить поведение от имени тестовой записи.
- При добавлении пользователя в группу может потребоваться новая сессия.
- Setgid на общем каталоге помогает новым объектам наследовать группу каталога.
- Предоставляйте только те права, которые нужны роли для выполнения задачи.
